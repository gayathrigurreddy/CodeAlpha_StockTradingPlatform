# Task 2 — Stock Trading Platform

Console-based OOP stock trading simulation.

## Features
- Stock market display
- Buy and sell operations
- Cash balance and portfolio tracking
- Average buy price and unrealized P/L
- Random market-price simulation
- Transaction persistence in `transactions.txt`

## Run
```bash
javac src/StockTradingPlatform.java
java -cp src StockTradingPlatform
```

> This is an educational simulation, not a real trading system.
